看到熟悉題目先別急，確認題幹是問「正確」還是「不」適切。

反向題處理法

  • 很多題目問「錯誤／不適切／不是」。讀到題幹的「不」，先在心裡標記
  • 四個選項逐一打 ✓✗，最後挑唯一的 ✗
  • 出現「一律、只要、僅、永久、完全、不需要」的選項，多半就是錯的那個
  • 管理科選「流程、授權、定期、全員參與」；技術科選「預設拒絕、白名單、伺服器端驗證」

最常搞反的六組

RPO / RTO資料遺失量 / 恢復時間
FAR / FRR誤放（危險）/ 誤拒（不便）
增量 / 差異相對上一次 / 相對上次完整
事件 / 事故觀察到異常 / 已造成或極可能造成衝擊
IDS / IPS只偵測告警 / 可即時阻擋
MDM / MAM管整台裝置 / 只管企業 App
